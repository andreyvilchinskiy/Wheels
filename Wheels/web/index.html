Пояснение к работе

В цикле вывода автопарка не используется instanceof или if, потому что toString() — виртуальный метод: JVM во время выполнения выбирает реализацию по фактическому типу объекта (Car, Motorcycle, Truck), а не по типу ссылки Vehicle. Это и есть полиморфизм.
